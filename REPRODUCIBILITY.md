# Reproducibility declaration

We, Aniruddha Bohra (P25CS0201) and Naveen Pratap (M26CSE017), declare that:

1. **All results in the report were produced by the code in this repository.** No number was copied from
   another paper or edited by hand. The classification tables (Tables 1, 2, 3 and 5 of the report) are generated
   by `cls/make_tables.py` directly from the per-run `results.json` files released in `results/cls/runs/`.
   Running
   `python cls/make_tables.py --runs results/cls/runs --out <dir>` reproduces them byte-for-byte; we checked
   this before submission. The figures are generated by `cls/make_figures.py` and `seg/make_seg_figure.py`.
2. **The test sets were used only for the final evaluation.** All settings were chosen on images held out from
   the training split (`--phase dev`). Final models were retrained on train+val and evaluated once on the
   official test splits. For ACDC, checkpoints were selected on the validation slices only.
3. **All methods share the same recipe, seeds and teachers.** Classification uses seeds 0, 1 and 2 for every
   method, and every student is distilled from the same ResNet-50 teacher file
   (`checkpoints/README.md`, SHA-256 listed). ACDC uses seeds 2345 and 1234 and one SAM ViT-L teacher.
4. **Every run is listed.** The job files we executed are in `cls/jobs_*.txt` and `seg/run_acdc.sh`. Each run's
   full argument list is stored next to its result (`args.json`, or the `Namespace(...)` line at the top of
   each ACDC `log.txt`). Training logs are in `results/cls/logs/` and `results/seg/logs/`.
5. **Reported limitations are not hidden.** Experiments we planned but did not run (ResNet-101 teacher,
   label-noise study, 2- vs 5-fold trust) are listed as not run in Sec. 7 of the report. Negative or neutral
   findings (CPT-KD closes only about 25% of the overall inheritance gap; it has little effect on ACDC; it is the
   identity on binary segmentation) are reported.

## Sources of non-determinism

`cudnn.benchmark=True` and bf16 autocast are used in the classification code for speed, so re-running a seed
gives numbers that match ours to roughly ±0.2 accuracy points, not bit-for-bit. The ACDC script sets
`cudnn.deterministic=1`, but bf16 and atomic operations can still cause small differences. The conclusions rest
on means over seeds and on paired (same-seed) differences, which are robust to this.
